    How it's made

    Every bar of this song is one week of my GitHub contribution calendar, in order. Drums follow the daily counts, busier weeks get more bass and melody, and the lyrics are filled in from the same numbers. A GitHub Action rebuilds the song, this page and the cover every night, so tomorrow it sounds a little different.
