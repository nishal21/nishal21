## What I'm working on

- [FirstPR](https://github.com/nishal21/firstpr): helps open-source beginners make their first PR themselves and get it merged. Finds a good first issue, shows which files it touches, and checks your PR before a maintainer does. Built with Anan Shaji. [Try it](https://firstpr.nishal.dev)
- [NekoDroid](https://github.com/nishal21/NekoDroid): an Android emulator that runs in a browser tab. Written from scratch in Rust, compiled to WebAssembly, no server. Runs bare-metal ARM and a small test APK today, not Play Store apps yet. [Docs](https://docs.nekodroid.tech/)
- [nishal.dev](https://github.com/nishal21/PortfolioV2): my portfolio. It has a voice agent you can call, with two voices (Cartesia and Fish Audio) behind one call bar. [Visit](https://nishal.dev)

## Other things I've made

- [Publicolio](https://github.com/nishal21/Publicolio): turns a GitHub profile into a portfolio page you can theme and share. [App](https://app.publicolio.qzz.io/)
- [World News CLI](https://github.com/nishal21/News-CLI): a full-screen news reader for the terminal, with AI summaries and read-aloud. [PyPI](https://pypi.org/project/worldnews-cli/)
- [UPI Down](https://github.com/nishal21/upi-Down): open it when a UPI payment fails to see which banks and apps people are reporting as down. No login. [App](https://upidown.nishal.dev)

More on [nishal.dev](https://nishal.dev).
